# Archive

Historical and source material lives here so the repo root can stay focused on the definitive sticker pack.

- `originals/` contains the downloaded `tk.sg/stickerlib` source assets and manifest.
- `chroma-key-sources/` contains flat green renders used to create the current transparent PNGs.
- `generated-iterations/` contains earlier generated attempts and style calibration history.
- `references/` contains copied visual references used during generation.
