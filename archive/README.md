# Archive

Historical and source material lives here so the working pack in `stickers/` stays small and obvious.

**Agents: do not browse this tree by default.** Open `stickers/manifest.json` first. Only follow a specific `source_path`, or the anchors listed below, when you need provenance or calibration.

## Layout

| Path | Contents |
| --- | --- |
| `originals/` | Downloaded `tk.sg/stickerlib` source assets and scrape manifest |
| `chroma-key-sources/` | Flat green renders used for many of the current transparent PNGs |
| `generated-iterations/` | Earlier attempts, rejected batches, and style calibration history |
| `references/` | Copied visual references used during generation (including full Kiap Kiap set) |
| `course-illustrations/` | Accepted 16:9 course-body sketches for the illustrations skill. Cited from `docs/skills/tkrobot-illustrations/references/worked-examples.md`. |

## Current anchors still cited from history

- Hand-size lock: `generated-iterations/v1-size-blocky-fingers/contact-sheet.png` — also mirrored at `docs/references/hand-size-anchor.png` for day-to-day use.
- Hatch Pet provenance for several pack additions: `generated-iterations/hatch-pet-v1/` (see that folder's `NOTES.md`).

Everything else under `generated-iterations/` is historical noise for pack work (rejected finger styles, intermediate limb widths, one-off pose retries). Keep it for archaeology; do not treat it as the style target.
