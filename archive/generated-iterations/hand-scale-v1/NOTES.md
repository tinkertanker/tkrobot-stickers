# Hand Scale v1 Notes

Test batch for larger T Krobot hands on selected poses:

- Palms targeted around 20% larger than the locked sticker pack.
- Fingers targeted around 10% longer on top of the larger palms.
- Original `gasp`, `handraise4`, and `shrug4` were used as proportion references.
- Definitive `stickers/` files were not overwritten.

Files:

- `sources/` contains chroma-key generated sources.
- `stickers/` contains transparent test PNGs.
- `contact-sheet.png` shows only the test outputs.
- `comparison-sheet.png` compares original, current, and test versions.
