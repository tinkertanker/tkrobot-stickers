# Original T Krobot Stickers

These files were downloaded from `https://tk.sg/stickerlib`.

`manifest.json` records the Zight collection item IDs, original CDN URLs, file sizes, and SHA-256 hashes. The captured source pages are kept so the scrape can be audited later.

Do not overwrite these originals. Put generated replacements under `generated/` with versioned filenames.
