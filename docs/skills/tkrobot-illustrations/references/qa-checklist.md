# QA checklist

Reject or edit when any of these appear.

## Character (check against the lock sheets first)

- T Krobot is decoration — standing beside the diagram instead of doing the work.
- Xiaohei drift: all-black silhouette, stick-figure limbs, capsule/pill head,
  two white dots for eyes.
- Limbs not light grey (black, white, chrome, or missing).
- Head not a softened trapezoid (rectangle, circle, lampshade).
- Glasses missing, shrunken, square, or filled with pupils/dots.
- Chest diamond missing, turned into bars, or moved to the shoulder.
- Mouth, eyebrows, blush, or a cute face.
- Thick sticker outlines or flat sticker shading on a sketch page.

## Page

- Canvas crowded: subject over ~60%, whitespace under ~35%, no quiet region.
- Reads as a flowchart, slide, architecture diagram, or polished flat illustration.
- Background not pure white (cream/texture/gradient/shadow).
- Annotations: more than 8, longer than ~5 words, misspelt, American spelling,
  or a type-title in a corner ("Workflow", "Roadmap"...).
- Extra type on props ("STAMPED", "WEEKLY BRIEFING", checkbox rows).
- Style drifted cute/childish, or mechanical/vector.
- More than one core idea in one image.
- A recycled composition from the examples or previous shots.

Prefer regenerate over heavy edits; the style is cheap to re-roll. When only
the character is wrong, use the on-model edit prompt in `prompt-template.md`
and re-attach both lock sheets. When only one label offends, use the title-removal
edit prompt.
